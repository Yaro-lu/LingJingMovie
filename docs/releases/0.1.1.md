# 灵境造片厂 0.1.1 · 更新说明

发布日期：2026-10-20。此版本集中修复内置 H3、模型下载、人物参考图与审核交互。

## 2026-10-20 同版本修订

- 程序更新使用与启动页一致的进度界面，显示备份旧版本、安装、校验文件、恢复与启动阶段；备份和校验显示实际文件数量，安装显示实际进度，并持续显示耗时。
- 更新期间可最小化窗口，重复打开会唤回更新页；失败时保留恢复结果和操作提示。备份、完整性校验与回滚机制继续保留，完成后自动交接到创作台。
- 修复可选 API 增值服务的状态显示：已确认关闭时，顶部与详情统一显示“未启用”；启动时读取调用信息失败后自动重试，详情补充“刷新信息”按钮与说明。
- 公网连接与 API 增值服务用于其他设备或软件远程调用本机。安装组件不等于启用服务；更新保留安装目录原有开关和配置，本机创作不依赖公网连接。

本次覆盖更新 0.1.1 安装包，版本号不变。已安装此前 0.1.1 的用户请重新下载安装包并覆盖安装，客户端不会把同版本修订提示为新版本。更新进度界面需要先安装新版更新助手后才能用于后续更新；旧版本助手执行本次升级仍可能静默，建议直接下载本次安装包安装。

## 内置 H3 与模型下载

- 修复内置 H3 工作流参数接口未能经本地桥接读取，导致误用通用视频尺寸、提交时报宽高必须为 32 整数倍的问题。
- 性价比 H3 与高质量 H3 按各自工作流映射首帧、随机种子、帧数和帧率。默认按首帧比例及工作流预算生成；明确指定尺寸时按 H3 要求对齐。其他模型参数规则保持不变。
- 镜像优先直连、官方源优先系统代理，连接失败尝试备用路径，不改系统代理设置。各路径暂时失败后保留断点，最多共三轮恢复，轮间等待 15 秒、45 秒。
- 暂停、取消与退出可中止重试等待；永久拒绝访问不反复尝试同源。文件身份、续传范围、大小及 SHA256 校验继续执行。
- 修复下载状态快照遇短暂文件占用时更新失败的问题，并补充下载连接与错误日志，便于定位网络异常。

## 人物参考图与创作提示词

- 人物三视图仅使用当前角色的视觉特征、穿着、配饰与独立美术风格，减少全片剧情、其他角色或场景串入当前人物的问题。
- 导演与工厂模式共用统一中文三视图模板：同一角色的正面、侧面、背面完整全身，自然横向排列，统一纯白背景；去除无条件枚举动物部位等易引起误解的描述。
- 改进人物身份、编辑快照与迟到回包校验，减少角色重排、删除或切换项目后结果贴错的情况。旧图片不会自动重新生成。
- 清理通用模板中预设的具体人物、物件、服装、场景、动作和默认创作偏向。风格与故事内容分别传递，避免风格描述擅自增加主体。
- 剧本生成与自动审核补充吸引力、内容推进、可视化表达、辨识度、核心记忆点、视听节奏与结尾表达要求，服从用户设定与时长预算；不增加独立模型调用阶段。

## 审核与成片交互

- 明确脚本审核后生成图片、图片审核后生成视频、视频审核后合成成片的作用。
- 图片和视频下支持逐项审核意见。“重新生成勾选项目”只处理所选内容；有意见时，由文字模型结合相关上下文调整提示词后重做。原有产物在修改失败时保留，文字修改与媒体重生成可能产生供应商费用。
- 成片放大或继续任务前检查当前项目、原版成片、所需组件及模型状态，展示暂停和失败原因、处理进度及前后尺寸，原版继续保留。
- 已有成片时，合成按钮显示“重新合成成片”；修改分镜或音频后可重新合成，已有成片可直接下载。

## 环境与启动

- 环境安装与修复窗口仅在首次成功激活支持者授权（包括首次恢复购买）后自动展示；后续由用户主动点击“一键修复环境”打开。检测缺项或上次修复未完成不再自动弹窗。
- 显存档位支持点击整张卡片切换，修复过程中保持交互锁定。
- 首次启动 GPU / PyTorch 检测遇暂时性超时或调用失败，会等待两秒复查一次；真实缺包或硬件不兼容仍提示处理，不自动安装或下载。
- 环境晚就绪时继续低频更新状态，服务已监听但节点尚未验证时继续刷新；新增启动阶段日志。历史首次失败原因仍需结合新日志确认。
