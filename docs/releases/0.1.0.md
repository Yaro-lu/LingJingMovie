# 灵境造片厂 0.1.0 · 更新说明

发布日期：2026-10-15。本版本汇总 0.0.5 之后的改进，包含此前未单独发布的 0.0.6 开发修改。

## 制作与审核

- 工厂模式在启动、恢复和重试前检查所选模型、账号连接、工作流资源及合成组件。检查失败显示具体原因，不会先创建新制作或覆盖原项目。使用第三方 API、即梦 CLI 时，无需安装未使用的本地显卡生成环境。
- 图片或视频任务明确生成失败后，工厂模式会用文字模型修正提示词，再重试一次；再次失败跳过该产物，继续其他分镜。缺少必要参考素材的后续产物也会跳过，进度中显示原因。账号、余额、配置及不确定提交需先处理，不盲目重提；文字修正和重新生成可能另行计费。
- 初期分镜自动审核未通过时，根据具体意见修改分镜提示词，再次审核；沿用自动修改轮数上限，超过上限转人工。
- “审核通过，继续”“按意见重新生成”“结束本次制作”和修改意见移到“等待你审核”状态栏下方，长脚本无需滚到底部操作。状态刷新保留正在填写的意见与视频播放节点。
- 生成、取消与失败重试提供更清晰的反馈，避免重复提交和旧结果写入已切换的项目；创作助手的图片、视频支持保存和失败重试。

## 下载、任务与连接

- 右上角小下载图标统一管理下载进度、暂停、继续、重试与取消。工作流资源选择仍在原生成模块，点击“下载”才建立任务；共用模型目录及关联状态识别更准确。
- 关闭程序时结束本机工厂制作、图片 / 视频生成和画质增强，重开不会自动恢复这些任务。只保留下载断点供续传，已完成项目与素材保留。供应商已接收的生成可能继续完成，无法保证通过关闭本机撤回。
- 后台子进程隐藏控制台窗口，减少生成、环境检查与维护时闪出命令窗口的问题。
- 修复 API 增值服务的后台启动异常。该服务供其他软件远程调用本机，桌面创作不依赖它；公网连接仍取决于相应组件、配置和网络状态。
- 即梦模型以当前 CLI 实际提供的能力为准；本次核对最新官方 CLI 未提供网页“图片美学模型 V8.2”，未添加猜测模型标识或替代映射。

## 项目、导出与帮助

- 未完成项目可导出 PR / 剪映工程：已有视频按顺序放入时间轴，缺失分镜按计划时长留空；全部视频缺失也能导出空时间轴。已有视频以实际时长为准，导出同时附带视频和 Word 导入教程。
- 作品库长摘要默认显示四行；文字悬停临时展开，移开收起；点击右下角箭头保持展开，再点击可收起，退出程序后恢复默认。
- 帮助页改为三步入门和十二个可展开问题，覆盖环境、模型、重试、审核、退出、续传和导出；加入[官网入门教程](https://lj.lol-lu.cn/guide.html)。
- 改进项目保存、删除、素材引用与清理，减少失败保存、迟到响应或多个任务同时操作造成的数据冲突。

## 程序更新与升级

- 主程序顶部显示版本号，每次打开静默检查 GitHub 更新。点击更新后后台下载，完成后提示“更新已就绪，下次启动安装”，由独立更新助手在下次启动处理。
- 改进升级、卸载及更新失败恢复：保留项目、模型、运行环境、授权和本地配置；保留自定义或修改过的工作流，更新失败提供恢复入口。程序恢复不回滚项目数据库。
- 升级前请等待当前制作完成或结束对应任务，再完全退出旧版本安装。建议先导出重要项目；缺失素材也可以先导出工程。
- PR 工程引用素材完整路径。移动导出目录或换电脑时，复制整个项目文件夹，并在剪辑软件中重新链接素材。

本次只发布 Protected 主程序安装包和 SHA256 校验文件。Python 自有代码编译为原生模块，JavaScript 自有代码混淆；可维护源码仅同步私有仓库。独立 ComfyUI 环境包保持 2.0.0，大型生成模型按需另行下载。

本版本为体验版，Windows Authenticode 数字签名尚未配置。验证包含源码回归、保护后运行检查、本地 API / Studio / 数据库及工程导出；真实 GPU 生成和全新 Windows 安装、升级、卸载仍需实机验收。
